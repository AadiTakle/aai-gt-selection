How to use — Bubble Pop Memory

Bubbles rise one at a time with a word inside. Tap POP (or press its key) only when the word in the bubble is the same as the word n bubbles ago — the rule line below the card tells you what n is right now. The first few bubbles are a warm-up: the buttons stay off until enough bubbles have gone by for a match to be possible. If a second lane appears, watch both and use each lane's own POP button.
