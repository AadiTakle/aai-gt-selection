How to use — Bubble Pop Memory

Bubbles rise one at a time with a word inside. For every bubble, answer once: tap Seen it if the word is the same as the word n bubbles ago, or New if it is not — the rule line below the card tells you what n is right now. Each button has a key you can press instead. The next bubble comes when you answer, so take the time you need. The first few bubbles are a warm-up with nothing to answer yet: the buttons turn on as soon as a match is possible. If a second lane appears, answer both lanes for each bubble.
